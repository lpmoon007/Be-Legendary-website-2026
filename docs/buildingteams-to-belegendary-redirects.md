# buildingteams.com → belegendary.org 301 redirects

**Status: to be set on buildingteams.com** (a separate site; not in this repo).
These consolidate executive-buyer queries onto belegendary.org and end the
cross-site cannibalization of two of our own pages competing for the same term.
Each belegendary destination already exists and is the stronger, on-brand page.

**Principle:** belegendary.org owns the serious executive-team buyer (offsite
planning, executive team building, sailing/experiential). buildingteams.com
keeps the corporate team-building activities and charity-events content. Where
both sites cover the same query, buildingteams 301s to belegendary — one
canonical page, consolidated authority, no self-competition.

## Before redirecting any page
1. **Salvage first.** If the buildingteams page has anything the destination
   lacks (a better template, checklist, a real quote), fold the good bits into
   the belegendary destination first — then redirect. (buildingteams.com blocks
   automated fetching, so this is a manual eyeball.)
2. Confirm the destination returns 200 (all do today).
3. Use a permanent 301 (not 302) so authority passes.
